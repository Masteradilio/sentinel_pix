⚙️ Arquitetura do Sistema v2.0

ComponenteTipoPapel
LightGBM v3 (Raw) Gradient Boosting (1500 trees, depth=7) Modelo principal — gera score raw (0-1) com 62 features
Motor de Regras 6 regras determinísticas Features para o LGBM: idade, relacionamento, conta mula, chave aleatória, velocidade, topaz
Isolation Forest 300 árvores, contaminação=1% Especialista em primeiras transações — detecta anomalias sem histórico
Mapeamento Híbrido Interpolação não-linear (12 âncoras) Converte score raw (0-1) → score intuitivo (0-100) com máxima separação
Preprocessor PixPreprocessor (custom) Limpeza, imputação de nulos e preparação das features
Fluxo: Transação → Features → LGBM Raw (0-1) → IF (1ª tx) → Ensemble Raw → Mapeamento Híbrido → Score 0-100 → Decisão (APROVAR / CONFIRMAR / BLOQUEAR)
